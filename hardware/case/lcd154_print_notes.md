# open-plaud LCD-1.54 Case — Print Notes

Parts:

- `open_plaud_lcd154_base.stl`
- `open_plaud_lcd154_lid.stl`

Target hardware:

- Waveshare ESP32-S3-LCD-1.54, SKU 33867
- Without touch control
- 3.7V battery included

Print request:

- Process: FDM
- Material: PLA for first fit test; PETG for a more durable second print
- Color: white or black
- Layer height: 0.20 mm
- Infill: 15-20%
- Walls/perimeters: 3
- Supports: no supports preferred; use only if slicer says required
- Quantity: 1 base, 1 lid

Important:

- This is a first-article case based on web dimensions, not caliper-measured hardware.
- Print the base first if possible. Test fit board, battery, USB-C, and microSD before printing more copies.
- Battery must not be squeezed. If the LiPo is tight, stop and revise the CAD.
- USB-C and microSD openings are intentionally generous and may need tuning after the board arrives.

Expected dimensions:

- Base: 49.0 x 49.0 x 21.5 mm
- Lid: 49.0 x 49.0 x 4.7 mm
- Assembled: about 49 x 49 x 23 mm
